3. Capabilities & how to test

Dynamic press listings live

The press hub and 9 brand hubs read the EDS press query index: live result counts, newest-first tiles, working company / topic / search / date filters and load-more. Brand hubs auto-scope to their company.

Test: open /en/press — the count ("64 results were found.") comes from the index. Pick a company in the Company filter, type a term in Search Term, click Load more. Then open /en/press/rwe-ag — the same block pre-filtered to RWE AG.

Mega menu live

The full live mega menu, cloned from measured recon: 10 sections with 193 links across 3 levels, hover-switching flyout panels (slide + fade, live timings), "Overview →" links, gradient newsbox teasers with images (The Group, Investor Relations, Press & News), body scroll-lock, burger→✕ swap. On mobile it becomes the live tap-through drawer with Back navigation. The whole tree is authored content in the /nav document (209 links) — editable without code changes.

Test: click Menu in the header — the white panel slides down with The Group open. Hover the left rail (e.g. Investor Relations) — the panel slides/fades to that section and the newsbox swaps. Click any link to navigate; press Esc or ✕ to close. At mobile width, tap a section to slide its panel in, then ← Back.

Site search live

Header magnifier opens the live-design search overlay: gradient gauze over the page, centered white rounded input with magnifier, ✕ in the header row — backed by the site-wide query index of all 616 pages.

Test: on any page, click Search and type hydrogen — up to 10 matching pages appear as a white results panel under the input; Esc or ✕ closes.

Consent management — Usercentrics live

The production RWE Usercentrics CMP (settings lrfueDZgn) loads in the delayed phase. GTM (GTM-K6ZG5P5) loads only after consent; etracker rides the CMP/GTM as on live. Bots/crawlers don't see the banner.

Test: open the home page in a private/incognito window — the RWE-branded "Welcome to RWE" dialog appears. In DevTools → Network, confirm no gtm.js before consent; click Accept All and see googletagmanager.com/gtm.js load. The footer link Cookies & Services reopens the settings layer.

Contact form (dynamic-contact-form) activates at cutover

The site's central contact form (the engine behind ~200 per-recipient configurations) is rebuilt with the exact live field set, honeypot and Cloudflare Turnstile, posting to the existing RWE endpoint /api/dcf with the ?c= config hash. Turnstile validates by domain, so real submissions activate once the site serves under rwe.com.

Test: open /en/contact-services/contact-form?c=… — the page personalizes exactly like live: "Vera Bücker will answer your questions", her photo/role/phone card on the right, Email preselected, privacy note. Try the careers variant: /en/rwe-careers-portal/contact-form?c={…}. Without a c parameter the generic form renders. On this pilot origin the Turnstile widget reports a domain error — expected; it passes on the rwe.com domain.

Specialised forms (Sitecore Forms) link-out

15 pages embed Sitecore Forms (newsletter, meeting request, RFPs…). Those use session-bound CSRF tokens that a static replica cannot mint, so they show a migration notice + button to the original form. Rebuilding them against a forms backend is a cutover decision.

Test: open /en/…/ir-newsletter — notice + "Open the form" linking to the live page.

Job search live API at cutover

The job list is wired to the live jobs API (POST /api/jobborse/entities/v1, verified: 208 jobs) with cards, total count, sort and load-more. The API sends no CORS headers, so on this pilot origin the block falls back to the frozen capture; at cutover (same origin) the live path activates unchanged.

Test: open /en/rwe-careers-portal/job-offers — 9 job cards with Apply-now links into SuccessFactors. (Pilot shows the frozen snapshot; the wired sort/load-more activate with the API at cutover.)

Authorable blocks built for the long tail live

Beyond the archetype blocks (hero, cards ×7 variants, banner ×4, press, quote, events, downloads, contacts, companies, icon-tiles, country-slider, locations-map, breadcrumb…), the bulk import added accordion, icon-list and table.

Test: accordions: /en/data-protection (16 expandable legal sections). Tables: bonds & sustainable finance (Senior Bonds tables). Icon list: D-Central.

Motion layer live

All animation contracts were measured on the live site (never invented): card entrances, contact-icon "wobble" stagger, header scroll morph, hover scales, button hovers.

Test: on home, scroll down — the six white cards fade up as they enter; the three contact icons pulse in live's stagger (2nd, 3rd, then 1st). Scroll down then slightly up — the compact gradient header bar slides in; back to top restores the full header.

Redirects live

1,721 redirect rules cover every excluded URL, so no English URL 404s.

Test: open an archived 2022 release, e.g. this one → 301 to the press hub. /en → home.

Query indexes (headless data) live

Three EDS indexes power the dynamic blocks and are open for any future consumer:

  • /en/press/query-index.json — title, image, description, publishdate, company, topics, teaser
  • /en/investor-relations/query-index.json — title, publishdate, category
  • /en/query-index.json — site-wide (616 pages), feeds search

Parameter-personalized pages — a migration class of its own

Pages whose live rendering depends on a query parameter are invisible to sitemap-driven discovery: the two contact-form pages render per-recipient via ?c= (the careers one wasn't in the sitemap at all — only reachable through parameterized links). Both are now covered by freezing all 31 referenced configs from live. The remaining parameterized links in the estate are filter-state deep-links (jobs ?ci=/?cm=, products ?kundengruppe=, experts ?expertise=, locations ?locationType=): those pages render fully, the parameter pre-filter is honoured when each listing's facet integration lands (jobs facets, products/experts listing wiring, map).

5. Quality assurance run (P5)

  • Link integrity: 978 unique internal targets — 610 resolve, 168 redirect; all 44 broken links verified equally dead on live rwe.com (inherited, not migration defects).
  • 1,674 images rehosted to the new content store; PDFs intentionally remain on origin.
